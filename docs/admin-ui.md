# 后台界面

后台采用 Art Design Pro 的纵向布局和组件样式，参考固定提交 `f3aaf58eec1a0e988f162352c33862327a484f95`。上游地址为 https://github.com/Daymychen/art-design-pro ，MIT 声明及参考文件见 `docs/licenses/art-design-pro.txt`。

## 当前集成

- 230px 侧栏、72px 折叠侧栏、60px 顶栏、42px 菜单项；900px 以下使用抽屉导航。
- 默认主色 `#5D87FF`；浅色、深色、主题色、侧栏折叠和表格密度保存在当前浏览器。
- 顶栏提供菜单搜索、刷新、全屏、外观设置、前台入口和用户菜单；发布按钮按菜单权限显示。
- 页签支持切换、关闭、关闭其他和关闭全部；搜索结果来自 Laravel 下发的当前用户菜单。
- 仪表盘使用真实统计，统一表格、表单、弹窗、编辑器和主题插件管理的外观。

这是与现有 CMS 业务集成的 Art 后台，继续使用同仓 Vue 3、Element Plus、Pinia、Vue Router 和 Laravel 接口。没有引入上游演示账号、模拟接口或无对应业务的入口。前台主题色与后台主色相互独立。

## 固定工作区与分页

后台以 `100dvh` 固定工作区，顶部、页签、页面标题保持可见。列表的筛选栏和分页固定在工作区上下方，记录区域单独滚动，表头和操作列固定。内容列表压缩封面、作者与统计列，摘要、专题和标签移到展开详情；手机仅保留内容和操作菜单，避免标题被操作列遮挡。内容搜索、过滤和翻页共用一个页签，并支持浏览器后退恢复查询。

内容、页面、通用资源、交易、媒体、链接检测、更新记录统一使用 `AdminPagination`，提供总数、每页条数、上一页/下一页；桌面另有页码和跳页，手机显示当前页/总页数。通用列表默认 20 条，选项 10/20/50/100；媒体默认 24 条，选项 12/24/48/96。后端验证 `page` 和 `per_page`，稳定按 ID 排序，并将因删除导致的空末页收敛到最后有效页。内容发布及快捷设置后刷新筛选结果和总数，避免已不符合筛选条件的记录仍留在列表。声明式扩展表格兼容 Laravel 分页响应或数组，数组使用客户端分页。

设置页固定保存按钮，主题设置分组导航、配置表单和保存栏分别布局。页面构建器保留恢复默认并固定保存栏。编辑器提供常驻预览/保存/发布操作，桌面正文和属性栏分别滚动，富文本和 Markdown 编辑区按视口高度调整。资源和内容设置弹窗在视口内限制高度，字段区域滚动、底部操作固定。更新维护分成版本更新、数据库与备份、扩展版本、更新记录、钩子诊断页签。

长表单、较多记录及小屏页面仍需要在内容区域滚动，后台顶部不会跟随滚走。数据库备份与扩展诊断等辅助列表使用区域滚动；无需把全部业务信息挤到同一屏。

本轮验证：`AdminPaginationTest` 等 25 项 PHP 测试、827 个断言通过；53 个后台入口在 1366×768、1440×1000、390×844 下共 159 次检查通过；Art 明暗模式及导航交互 36 次检查通过。新增 `scripts/browser-admin-workspace.py` 与 `scripts/browser-admin-pagination.py` 检查顶部固定、分页可见、真实翻页/改条数/跳页、过滤发布、末页删除、手机操作菜单、弹窗与保存栏。主题设置与恢复默认专项回归通过，Markdown 32 种正文主题、9 种代码主题与组件隔离回归通过。TypeScript、Pint 和生产构建通过，构建仍有现有大 chunk 及运行时资源路径提示。所有浏览器业务写入均在专用 SQLite 测试站完成，分页脚本创建的记录在结束时清理，未修改当前 MySQL 业务数据。

## 前台主题设置

入口：外观管理 → 主题设置（`/admin/theme-settings`），需要 `manage themes` 权限。三套内置主题分别保存配置，可以编辑未启用的主题；切换下拉选项会保留当前页面中各主题的未保存修改。导航离开或刷新前会提示未保存内容。

| 分组 | 可配置内容 |
| --- | --- |
| 品牌导航 | 标识、Logo、浏览器图标、副标题、固定导航、搜索、投稿与会员入口 |
| 配色布局 | 强调色、页面宽度、侧栏宽度与位置、卡片圆角、内容间距 |
| 首页内容 | 横幅图片与文案、跳转地址、公告、分类、侧栏资料与会员模块、内容数量 |
| 列表卡片 | 首页与频道的列表/网格、封面比例、默认封面、摘要、作者与统计 |
| 文章阅读 | 侧栏、作者与相关推荐、封面、摘要、标签、日期、阅读量、正文字号与行距 |
| 页脚信息 | 页脚文字、备案号、页脚菜单、返回顶部 |

图片字段可选择媒体库图片或输入地址，上传和媒体管理沿用现有媒体权限；仅有主题权限的作者仍可输入图片地址。关闭上级开关会隐藏关联选项并保留已有值。搜索按字段名称与键匹配；“重置此分组”和“恢复默认”分别回填单组、当前主题全部字段，保存后生效。预览打开独立页面，有效期 10 分钟，只有创建它的管理员可见，不切换公开主题。首页启用页面构建器时由构建器负责正文布局，主题原生首页选项在关闭自定义布局后生效。

三主题共用响应式布局，在配色、内容默认布局和封面比例上保留差异。样式位于 `resources/css/theme-refinements.css`，仅作用于内置主题，不覆盖第三方主题或 Markdown 组件。布局宽度和阅读排版采用经服务端验证的 CSS 变量；历史分 scope 的开关在管理员首次保存对应全局选项前继续生效。配置不会调整支付价格、内容可见性或下载权限。

验证命令：`ThemeAppearanceTest`、`AppearanceDefaultsTest`，以及专用 SQLite 浏览器站上的 `python scripts/browser-theme-settings.py` 和 `python scripts/browser-appearance-defaults.py`。脚本临时修改并恢复测试站主题/布局，不访问当前站点 MySQL。

## 编辑器与重置

主题设置和页面构建器提供“恢复默认”，确认后回填当前表单，点击保存后生效。取消不会改变编辑内容。主题设置恢复当前主题表单中的字段，默认值由主题清单和字段定义提供；其他主题、文章的 Markdown 样式和站点全局设置不受影响。页面构建器恢复初始区块并关闭“启用自定义布局”，保存后使用主题原生页面，布局名称和发布状态保持当前值；重新打开开关并保存可启用构建器布局。

Markdown 正文主题、代码主题各自限定到文章容器，切换时保留短代码组件交互状态。主题 CSS 在 Vite 构建时通过 PostCSS 解析，动画名称加主题前缀；不在浏览器解析第三方 CSS。短代码、代码工具栏、公式和图表不套用正文主题。扩展作者可在组件根节点添加 `data-markdown-component` 来隔离正文排版。代码颜色只由“代码主题”控制，多个预览或文章可以同时使用不同主题；预览卸载后释放对应样式。下载卡按文章容器宽度响应，适用于分屏编辑和手机。

专项回归：`node --test tests/frontend/markdown-theme-css.test.mjs`、`AppearanceDefaultsTest`，以及隔离浏览器站点上的 `python scripts/browser-markdown-themes.py`、`python scripts/browser-appearance-defaults.py`。
