# 站长使用指南

## 内容与建站

在“内容”或“页面”创建内容，可切换块、富文本和 Markdown。复杂块转 Markdown 后保存在 `zfy-document` fenced block 中，切回时恢复结构。旧 Markdown 原稿、自动保存和修订可恢复。没有发布权限的作者提交待审，公开文章修改进入待审修订时保留现有公开正文。

保存后展开“购买与下载”，设置售价、VIP 免费、访问范围、内容密码、下载次数和 SEO。密码留空保留原密码；修改密码使以前的解锁凭证失效。权限块中的密码条件使用当前文章的内容密码。私有附件上传后绑定当前内容。

分类、标签、专题、评论从对应管理页维护。定时发布日期由计划任务处理。搜索只查询公开标题和摘要，受限正文不会进入索引。

“外观”管理主题、导航、小工具与首页布局。主题设置预览只对当前管理员生效。第三方主题通过 ZIP 安装，声明自身模板、资源和设置；页面构建器支持组件排序、列数和桌面/手机可见性。

页面构建器可添加容器并嵌套组件，最多四层、100 个区块；每层分别设置桌面/手机列数和间距，访问条件在服务端执行。编辑器支持段落缩进、行内代码、符号表情和表格行列操作。

保存内容后可在“图集图片”批量上传，拖拽或上下移动排序，编辑标题、说明、版权和单图权限。原图与预览图均保存在私有存储，前台只输出有权限的图片；原图下载默认关闭，启用后仍受登录、内容权限和下载次数限制。GD 生成去元数据、最长边 1600px 的预览 JPEG；仅公开单图可选作封面，受限文章的封面仍受整篇访问条件约束。

菜单支持最多四层，用层级与排序控制父子关系；可限制游客、登录会员或指定后台角色可见，父菜单不可见时其子树也不会显示。

## 会员与交易

VIP 支持月、季、年和永久周期，订单保留权益快照。钱包充值使用已配置外部渠道；余额和积分可支付订单。用户中心显示流水、订单、下载、通知和作者收益。

商品支持数字资源、卡密和实物，可添加 SKU、规格价格与库存。购物车选择地址和优惠码后获取报价，下单预留库存；取消/超时释放可释放的预留。存在未确认外部支付时，需要先渠道查单或关单。

运费模板按同模板商品合并计费：首件数量内收首件运费，其余按每件续费，可设满额包邮。区域规则按顺序匹配收货地区前缀，第一个匹配项生效；可覆盖费用或禁止配送。具体地区规则应放在省级规则前。

实物付款后进入待发货，后台填写承运商和运单号，买家确认收货。商品订单可按金额部分退款，留空退剩余金额；内容、会员和充值订单按全额退款。部分退款保留交付权益，累计退完撤销权益；已发货实物经后台退货验收后恢复库存，已交付卡密不重新上架。官方渠道确认退款后才冲回权益和分成，人工渠道必须记录凭证。

用户订单页选择余额支付时，可按 10 积分抵 1 元追加积分抵扣。积分与余额同事务扣除，分成只按现金部分计算；退款按累计金额比例返还原积分和余额，最后一笔返还舍入余数。外部渠道与积分组合支付暂不支持；部分退款按金额处理，不提供按 SKU/数量选择退货的操作界面。

作者规则依次选择内容、作者、分类、全站默认，冻结期收益不进入可提现余额，有未处理退款时暂停结算。提现先冻结余额，拒绝释放，支付记录凭证。退款时分成已被提现可产生欠款余额，后续收益抵扣。

## 账户与运营

资料、验证邮件、密码重置、通知、签到、作者申请、举报和申诉使用真实数据。设备管理需要数据库会话。敏感词与评论审核设置参与提交校验。后台权限由 Laravel 判断，浏览器隐藏菜单不替代授权。

用户中心可发送和回复私信，敏感词命中审核规则时进入后台“私信审核”，通过后才向接收者发送队列通知。每用户每天最多 100 条，接口另有分钟限流。超级管理员可在“角色权限”编辑四个内置角色的权限；初始化脚本复跑会保留已编辑权限。

## 扩展与维护

PHP 和 Blade 是管理员信任的扩展代码，系统不提供恶意扩展沙箱。依赖不满足会阻止启用；停用、卸载保留数据，卸载后的数据清理是独立操作。

后台检查版本后点击安装，计划任务执行签名校验和更新。离线更新同样需要包、清单和签名。更新期间不要直接修改数据库或扩展目录。恢复命令见 [updates.md](updates.md)。常规维护可使用“重建搜索索引与模板缓存”。

演示内容运行 `php artisan db:seed --class=CmsDemoSeeder` 导入，不给管理员充值、不改密码、不覆盖已编辑内容、不生成虚构已支付订单。
