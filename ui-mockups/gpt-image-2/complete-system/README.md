# zfy-blog 完整系统 UI 图片索引

本目录按三种首页风格分别生成了完整系统 UI 图，均使用 `gpt-image-2` 生成。每种风格包含 38 张页面图，共 114 张 PNG。

## 风格目录

| 风格 | 目录 | 定位 |
| --- | --- | --- |
| A | `style-a-blue-gaming/` | 蓝白游戏资源社区风，强调综合内容流、资源下载、VIP、排行和后台管理效率 |
| B | `style-b-marketplace/` | 蓝白资源商城/交易平台风，强调商品卡、付费下载、优惠、订单和商业化 |
| C | `style-c-creative/` | 黄粉创意资源站风，强调创作者社区、轻快视觉、资源瀑布流和会员转化 |
