# zfy-blog 页面 UI 图索引

本目录使用 `gpt-image-2` 生成，分为两套风格：

- `a-*`：蓝白游戏资源社区风，适合偏游戏、资源下载、会员资源站。
- `b-*`：黄粉创意资源站风，适合偏创作者社区、设计资源、轻商业平台。

## 前台页面

- `a-content-detail.png` / `b-content-detail.png`：统一内容详情页
- `a-file-detail.png` / `b-file-detail.png`：资源下载详情页
- `a-images-detail.png` / `b-images-detail.png`：图集详情页
- `a-vip.png` / `b-vip.png`：VIP 会员页
- `a-user-center.png` / `b-user-center.png`：用户中心
- `a-author-profile.png` / `b-author-profile.png`：作者主页

## 后台页面

- `a-admin-dashboard.png` / `b-admin-dashboard.png`：后台仪表盘
- `a-editor.png` / `b-editor.png`：内容编辑器
- `a-media-library.png` / `b-media-library.png`：媒体库
- `a-orders-payments.png` / `b-orders-payments.png`：订单与支付管理

## 使用建议

先选定全局风格 A 或 B，再针对单个页面挑选可融合的局部模块。生成图中文字可能存在不稳定，主要用于确认视觉风格、布局密度和信息架构。
